# evaluate-carbon-aware-workflows

This repository contains the results and evaluation for our paper, "A Systematic Evaluation of the Potential of Carbon-Aware Execution for Scientific Workflows" (more details in the Publications section below), which expands on the work initially explored in [Exploring the potential of carbon-aware execution for scientific workflows](https://ieeexplore.ieee.org/abstract/document/11044837).
